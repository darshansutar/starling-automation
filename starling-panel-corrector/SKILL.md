# Starling Panel Corrector

Follow the [required reference bundle](../starling-animation-pack/references/reference-bundle.md): character sheets, matching environment, prop sheets, then the narration storyboard or existing clean dialogue scene. Check that production owners have generated and inspected missing sheets/environments before submission; retain the existing dialogue audio route. Repair-only exception: after a generated animation is reviewed as needs_fix, use scene-specific single-character, individual prop and matching environment references for that failed clip, following the repair procedure in the shared reference bundle. Normal first submissions use sheets; dialogue keeps its clean scene and accepted speech.

Read [visual routing](../starling-animation-pack/references/visual-routing.md) and [spatial fidelity](../starling-cinematography/references/spatial-fidelity.md). Compare the actual image against canonical source, approved style/assets and shot plan. Review-only invocation returns findings; image edits require an authorized production/repair scope and completed intake.

Inspect the complete asset/scene and both storyboard pictures and labels of each narration clip. Enlarge uncertain details. Check identity, visible cast count, wardrobe/accessories, anatomy, hands, props, ownership, set/light, expression, action readiness and branch state. Apply every applicable spatial check: scale/proportion, perspective/depth, separation/clearance, support/contact, orientation/construction, occlusion and continuity. Different viewpoints can legitimately change apparent size and visible faces.

Check picture-area dimensions, upper/lower shot order, readable SHOT/time/CAMERA/ACTION labels below each picture, matching metadata and action-ready staging. Check that artwork contains no arrows or motion symbols. A source-supported action must be possible from the pictured staging. Source image quality and completed animation quality are separate gates.

Record exact file hash, panel/region, observed versus expected state, severity and smallest repair. Use native image editing with the defective version and relevant references. Preserve correct content. Reinspect the entire corrected board/scene and rerun affected Director/Cinematography checks. Both pictures, label accuracy and shot-continuity checks must pass. Bound repairs to observed defects; report unresolved problems rather than polishing indefinitely.

Save panel_qa.json and version lineage; update affected manifests and invalidate dependent prompts for review without changing or resubmitting existing paid jobs. Do not rewrite speech or outcomes to accommodate a visual defect.
