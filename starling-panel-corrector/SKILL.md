# Starling Panel Corrector

Read [visual routing](../starling-animation-pack/references/visual-routing.md) and [spatial fidelity](../starling-cinematography/references/spatial-fidelity.md). Compare the actual image against canonical source, approved style/assets and shot plan. Review-only invocation returns findings; image edits require an authorized production/repair scope and completed intake.

Inspect the complete asset/scene and both panels of each board. Enlarge uncertain details. Check identity, visible cast count, wardrobe/accessories, anatomy, hands, props, ownership, set/light, expression, action readiness and branch state. Apply every applicable spatial check: scale/proportion, perspective/depth, separation/clearance, support/contact, orientation/construction, occlusion and continuity. Different viewpoints can legitimately change apparent size and visible faces.

Check board geometry, top/bottom order, useful shot distinction and clean presentation. A source-supported action must be possible from the pictured staging. Source image quality and completed animation quality are separate gates.

Record exact file hash, panel/region, observed versus expected state, severity and smallest repair. Use native image editing with the defective version and relevant references. Preserve correct content. Reinspect the entire corrected board/scene and rerun affected Director/Cinematography checks. Both panels and board-level checks must pass. Bound repairs to observed defects; report unresolved problems rather than polishing indefinitely.

Save panel_qa.json and version lineage; update affected manifests and invalidate dependent prompts for review without changing or resubmitting existing paid jobs. Do not rewrite speech or outcomes to accommodate a visual defect.
