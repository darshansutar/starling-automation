# Starling Director

Follow the [required reference bundle](../starling-animation-pack/references/reference-bundle.md): character sheets, matching environment, prop sheets, then the narration storyboard or existing clean dialogue scene. Check that production owners have generated and inspected missing sheets/environments before submission; retain the existing dialogue audio route. Repair-only exception: after a generated animation is reviewed as needs_fix, use scene-specific single-character, individual prop and matching environment references for that failed clip, following the repair procedure in the shared reference bundle. Normal first submissions use sheets; dialogue keeps its clean scene and accepted speech.

Read [the handoff](../starling-prompt-pack/references/handoff-contract.md), [narration storyboard planning](../starling-animation-pack/references/narration-pairs.md) and [spatial fidelity](../starling-cinematography/references/spatial-fidelity.md). Own meaning, staging and action continuity; generation remains with production owners.

Map all semantic beats to source lines and measured audio. Specify visible people/objects, intention, starting state, required action and actual outcome. Preserve the full cast, branch differences and proposed-versus-completed work. Keep finalized-document content authoritative.

Plan two related shots per narration storyboard, each communicating source meaning through truthful staging and supported action. Match the below-picture action/camera labels to the planned shots and one measured hard cut. Quiet scenes use a gentle zoom or small pan while all subject/object states stay fixed; do not invent activity. Preserve time of day, sky, lighting and shadows unless the script explicitly requires a transition. Use the two shots for meaningful related views; preserve complete source coverage. Include recognizable introductions, meaningful contextual B-roll and opening/true-ending coverage as production staging within canonical nodes. Preserve separate dialogue scenes and mixed-node order.

At image review check the actual compositions communicate the required information with believable staging/contact and correct outcome state. At video review inspect the complete action, reactions and sound, including intermediate motion. Reject unsupported additions or altered results. Panel Corrector owns detailed still repairs; Cinematography owns shot geometry. Missing inspection remains unverified.

Record director_review.json with exact source/output versions, panels or actual time ranges, observations, verdicts and minimum repair owner. A review invocation does not generate or submit repairs.
