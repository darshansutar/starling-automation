# Required animation references

Inspect the storyboard or clean dialogue scene before choosing references. Every new animation request must include these reference groups in order:

1. Approved character sheets for the scene's characters.
2. A matching environment reference showing the actual location, layout, lighting and fixed equipment.
3. Approved prop sheets covering the scene's objects and their required states.
4. The inspected labelled 1x2 storyboard for narration, filler, establishing and ending clips. Dialogue retains its inspected clean full-frame scene and accepted reference audio.

For first submissions, use character sheets and prop sheets. The repair-only exception below permits individual references after an incorrect animation output. A sheet may cover one identity or one object through useful consistent views. Reuse approved sheets when suitable. Generate and inspect a missing character sheet, scene-specific environment or prop sheet before proceeding; a broad location reference containing unrelated equipment is not a match. Sheet views describe the same identity/object, not extra scene occupants or duplicated objects.

Keep all four groups present. For a person-free insert or a shot without a handheld prop, use the same source scene's character sheet and relevant fixed equipment/object sheet as context, explicitly mapping their visibility per shot. Context references do not authorize adding people or objects to the storyboard. If the source scene has no valid reference for a required category, hold submission and resolve the reference plan rather than inventing a subject or silently omitting the group.

Save ordered roles, filenames, hashes, upload names and per-shot visibility. Rebuild Picture indexes after any reference change. Check all required groups and every pictured identity/object before submission. If the complete bundle exceeds the provider limit, consolidate compatible approved sheets or split the planned clip at a source-supported cue; retain all required reference groups.

## People standing together

Stage adjacent people with a clear visible gap between their shoulders, torsos, arms, hips and feet. Give each a separate standing position and enough room for the planned gesture. This applies to every pairing, including a woman and a man. Preserve believable conversational distance, eyelines and shared perspective. Intentional contact must be supported by the script and explicitly staged. Check both storyboard pictures and the entire animation for merged silhouettes, body intersections or loss of the planned gap.

## Repair-only individual references

When inspection of a generated animation identifies an incorrect output, record needs_fix, the visible defect and the original job ID. For that failed clip, generate and inspect scene-specific single-character references, individual prop references and a matching environment from the approved sheets, style and script. Keep identity, costume, object state, scale, lighting and layout consistent. Use only subjects relevant to the inspected storyboard; a new reference does not add a subject to the scene.

Send the repair bundle in the same order: character references, environment, prop references, then the inspected storyboard. Dialogue retains its clean scene as the final visual and its accepted speech and turn mapping. Correct the storyboard when it contains the defect, then analyze it again and rewrite the affirmative animation prompt against the actual replacement images. Rebuild Picture indexes, record reference hashes and preserve originals and paid-job IDs.

This exception is only for a reviewed failed output, not routine first generation. It uses the existing single repair attempt; it does not add another automatic retry cycle. Review the complete repaired picture and sound. If it remains incorrect, retain needs_fix and report it rather than continuing automatic regeneration. Review-only skills identify the repair and route it to production; they do not generate media.
