# Scene preservation and animation prompt contract

Read [visual routing](visual-routing.md), [narration storyboards](narration-pairs.md) and [spatial fidelity](../../starling-cinematography/references/spatial-fidelity.md). Canonical script/audio control meaning and timing. Approved panels control actual composition and visible state. Asset references reinforce only their assigned identities/materials.

## Plan each shot from the inspected image

Record visible actor/object IDs, counts, positions, ownership and contact; permitted action with start/movement/end and measured interval; preserved identity, proportions, set/light and background state; locked camera; cut timing. Required motion must be possible from the actual staging. Repair an incompatible image upstream. State relevant relationships clearly rather than repeating generic failure lists.

Movement stays within each shot and follows source meaning. Quiet object coverage may remain still. Human activity should be restrained and supported, not repeated gestures added to fill time. Preserve contact, balance, clearance, depth, scale and object orientation through the complete action. All unassigned background elements retain their approved state.

## Mode-specific prompt

Both routes use the [five-section reference template](animation-template.md). Narration follows [storyboard planning](narration-pairs.md): two related full-frame colour shots, one measured hard cut and relevant ordered refs. Caption strips guide production. Express the target positively. Dialogue retains approved speech and exact turn mapping. Save shot_inventory_match for both routes; inspect all motion before acceptance.

## Complete review and targeted repair

After collection inspect the whole picture and sound against the approved plan, including action progression, spatial fidelity, intermediate contact, cut time, fixed framing, identity, branch outcome and absence of unintended overlays or speech. Save actual methods/time ranges and source/output hashes. Samples can locate a defect; they cannot pass a complete-motion check.

Use the Animation Pack's one-time scene-redesign rule after an initial visual failure: retain the script beat and approved style, generate and inspect different staging, then submit one EN2 Fast replacement. Record the failed output, defect, redesigned scene's source/audio mapping, new image hashes, prompt and replacement ID under the same logical clip. A second failure stops for user review; do not loop through scenes, prompts or seeds. A provider error or unknown submission is not a visual failure: reconcile its status before any further action, without using it to reset attempt history. FFmpeg still-image animation replacements are disabled; preserve historical alternatives without selecting them for current production.
