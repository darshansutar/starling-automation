# Scene preservation and animation prompt contract

Read [visual routing](visual-routing.md), [two-shot boards](narration-pairs.md) and [spatial fidelity](../../starling-cinematography/references/spatial-fidelity.md). Canonical script/audio control meaning and timing. Approved panels control actual composition and visible state. Asset references reinforce only their assigned identities/materials.

## Plan each shot from the inspected image

Record visible actor/object IDs, counts, positions, ownership and contact; permitted action with start/movement/end and measured interval; preserved identity, proportions, set/light and background state; locked camera; cut timing. Required motion must be possible from the actual staging. Repair an incompatible image upstream. State relevant relationships clearly rather than repeating generic failure lists.

Movement stays within each shot and follows source meaning. Quiet object coverage may remain still. Human activity should be restrained and supported, not repeated gestures added to fill time. Preserve contact, balance, clearance, depth, scale and object orientation through the complete action. All unassigned background elements retain their approved state.

## Reference prompt

Use the [five-section animation template](animation-template.md) for subject_definitions, summary, retention_analysis, detailed_description and overall_soundscape. It owns the ordered reference map, per-reference preservation labels, per-shot visible inventory and concrete action wording. Record shot_inventory_match by comparing the final prompt and actual reference assignments with both inspected panels.

Both storyboard shots need adequate measured time. The cut is direct; preserve scene geometry without blended/morph transitions. Narration characters are silent with relaxed closed mouths. Dialogue lip-sync belongs only to the current speaker. Keep narration master/transcript outside the board render. Reference sheets do not become scenes or extra people.

Write the actual scene and permitted actions once. Add exclusions only when needed for that scene or an observed defect. Prompt compliance is a request, not proof of render quality.

## Complete review and targeted repair

After collection inspect the whole picture and sound against the approved plan, including action progression, spatial fidelity, intermediate contact, cut time, fixed framing, identity, branch outcome and absence of unintended overlays or speech. Save actual methods/time ranges and source/output hashes. Samples can locate a defect; they cannot pass a complete-motion check.

Repair the smallest affected source, prompt or render through the owning skill and EN2 Fast. Reinspect each complete replacement. Maximum two replacements after the initial attempt unless the user changes the limit. An exhausted or unavailable review remains blocked. FFmpeg still-image animation replacements are disabled; preserve any existing alternatives as history without selecting them for current production.
