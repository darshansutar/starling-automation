# Starling Image Pack Generator

Check [mandatory intake](../pipeline/INTAKE.md), accepted audio and the approved Prompt Pack. Read [visual routing](../starling-animation-pack/references/visual-routing.md), [two-shot boards](../starling-animation-pack/references/narration-pairs.md) and [spatial fidelity](../starling-cinematography/references/spatial-fidelity.md). Use native ChatGPT image generation/editing and the installed imagegen skill. Own image production, not video or script rewriting.

Generate final-colour character references, environments and props in dependency order. Inspect each before attaching it to a dependent request. Use actual selected style images and the full required cast. Then generate each 1x2 board or clean dialogue scene from its approved prompt and assigned references. Keep prompts specific to visible subjects, composition and physically plausible interactions.

Every board has exactly two stacked borderless panels: two related shots. Preserve intended per-panel aspect without stretching. Keep labels/timings/camera instructions in the manifest. Clean dialogue images show actual participants without printed planning content.

Immediately inspect the full output and both panels at useful resolution. Apply Panel Corrector plus Director/Cinematography checks, including anatomy, identity, scale, perspective, contact, clearance, front/back orientation, occlusion and cross-panel continuity. Repair only observed defects using the actual image and required references; reinspect the complete replacement.

Save durable originals and corrected versions with real file type, dimensions, SHA-256, integer panel boxes, source IDs, input/reference mappings, generation provenance and review evidence in image_manifest.json. Validate JPEG delivery where required by the upload contract; changing a filename is not conversion. Both panels and the board-level composition must pass before animation. Unresolved checks stay unverified; preserve earlier versions and paid-job history.
